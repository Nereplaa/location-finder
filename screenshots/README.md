# Ekran Görüntüleri

Bu klasör AKİS uygulamasının ekran görüntülerini içerir.

## Beklenen Dosyalar

| Dosya | İçerik |
|---|---|
| `01_musteri_ana_sayfa.png` | Müşteri ana sayfası — arama çubuğu ve kategoriler |
| `02_urun_detay.png` | Ürün detay sayfası — stok durumu ve kat haritası |
| `03_magaza_dashboard.png` | Mağaza sorumlusu paneli — uyarılar ve analitik |
| `04_admin_raporlar.png` | Admin raporları — trendler ve dağılım grafikleri |
| `05_kiosk_ana_sayfa.png` | Kiosk terminal ana sayfası — dokunmatik arayüz |
| `06_kiosk_harita.png` | Kiosk interaktif AVM kat haritası |

## Ekran Görüntüsü Almak İçin

1. Uygulamayı başlat: `run.bat` veya `flask run`
2. Seed verisi yükle: `python seed.py`
3. Her sayfayı tarayıcıda aç ve ekran görüntüsü al
4. Bu klasöre kaydet
